# ScopeBoard — 21-Day Revision Notes

This folder contains one Markdown file for each revision day.

## How to use
1. Open the file for the current revision day.
2. Revise the topics one by one.
3. Add explanations in your own words and paste only code you understand.
4. Complete the practical exercise and quiz.
5. Tick the completion checklist and record your confidence.

## Files
- `Revision-Day-01.md` through `Revision-Day-21.md`

The topic lists are pre-filled from the revision plan. The remaining sections are structured spaces for explanations, code, exercises, troubleshooting and quiz answers.
